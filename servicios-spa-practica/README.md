# Proyecto práctico: sitio web para servicios de spa

Proyecto práctico desarrollado para reforzar conocimientos de desarrollo web, conexión entre frontend y backend, consumo de APIs y flujo de citas/servicios.

## Tecnologías utilizadas

- React
- Node.js
- Express
- MySQL
- Axios
- Vite
- HTML
- CSS
- JavaScript

## Estructura del proyecto

```text
src/           Backend con Express
spa-frontend/  Frontend con React y Vite
```

## Funcionalidades practicadas

- Consulta de catálogo de servicios
- Categorías de servicios
- Flujo de selección y carrito
- Disponibilidad de citas
- Simulación de pago/confirmación
- Comunicación entre frontend y backend mediante APIs

## Instalación

### Backend

```bash
npm install
cp .env.example .env
npm run dev
```

### Frontend

```bash
cd spa-frontend
npm install
cp .env.example .env
npm run dev
```

## Nota

Proyecto práctico no publicado y no completado en su totalidad. Se comparte como evidencia de aprendizaje en React, Node.js, APIs y bases de datos.
